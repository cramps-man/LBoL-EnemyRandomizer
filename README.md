## A modded exhibit replacer for Act 1 boss

This mod is intended for use with other character mods installed.  
The Act 1 boss will give alternate reward exhibits only from modded characters.  
This is to allow playing with those character card pools even if they don't have an Act 1 boss.  

### Optional configs

ReplaceLeftExhibit: replaces the leftmost exhibit with a modded exhibit, default: false  
ReplaceBottomExhibit: replaces the bottom exhibit with a modded exhibit, default: false  
ReplaceBossExhibit: replaces the boss exhibit with a modded exhibit, default: true  
  
DoReplaceAct1: default, true  
DoReplaceAct2: default, false  
DoReplaceAct3: default, false  
  
AllowDifferentColorReplacement: Allows replacing individual exhibits with different colored exhibits, default: true  
AllowSameCharacterExhibit: Allows obtaining exhibits from the same character, default: true
